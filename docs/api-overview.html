Chinese Learning App — Tổng quan API & Service

Diễn giải toàn bộ API backend, endpoint AI và service nội bộ đang dùng.

Backend chính: Directus @ https://marutek.space

1. Auth & User (REST)

Cấu hình tại api/authConfig.ts — tự gắn Bearer token, retry lỗi mạng/5xx, tự refresh khi 401. Gọi trong api/apiService.ts.

MethodEndpointChức năng
POST/auth/loginĐăng nhập
POST/auth/forgot-passwordQuên mật khẩu
POST/graphql/systemLàm mới token (auth_refresh)
GET/users/meThông tin người dùng
GET/items/user_profilesHồ sơ người dùng
POST/filesUpload file (multipart)

2. GraphQL

Client tại api/graphql/client.ts: graphqlRequest → POST /graphql, graphqlRequestSystem → POST /graphql/system. Dùng cho toàn bộ nội dung học.

api/bilingual.tsBài đọc song ngữ, genre, HSK level, grammar of section, submit exercise, video section
api/grammar.tsGrammar modules & items
api/speaking.tsSpeaking topics / scenarios / dialogues
api/stories.tsBook library, genre, latest/trending/popular, reading progress
api/vocabulary.tsTừ vựng, dictionary levels
api/notebook.tsFlashcard deck & items, vocab display map
api/target.tstarget_user (mục tiêu học)
api/profile.tsCập nhật user_profiles, targets
api/video.tsVideo genres / sections
api/user.ts/user/me, /user/:id/topics, xóa tài khoản (delete_users_item)

3. Directus Flows

Gọi qua /flows/trigger/<id>, định nghĩa tại lib/constants.ts. Các nghiệp vụ phía server:

  • Register, Update profile, Reset password, Onboarding email check
  • Exercise count (by topic / by lesson & topic), Exercise by id, Submit exercise
  • Get targets, Update target user, Account type, Update topics of interest
  • Vocab detail, Add note to vocab, Update note vocab, Flashcard deck vocabs
  • Update HSK level
